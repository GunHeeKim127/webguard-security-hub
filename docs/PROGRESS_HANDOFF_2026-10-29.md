## Mac 오류의 현재 상태

담당자 진단은 도구2026-10-29.3 / darwin / dmg / stability / FILE_CHANGED_DURING_INSPECTION이다. 구버전에는 어떤 속성이 달라졌는지 근거가 없어 ctime만의 변화인지 실제 내용 변화인지 확정할 수 없다.

2026-10-29.4는 OS 검사 전후 전체 해시를 대조한다. 파일 교체·크기/mtime·바이트 변화는 계속 차단한다. ctime만 달라지고 내용 해시·식별자·크기·mtime이 같을 때만 메타데이터 변화로 기록한다. 설치 시각은 검사하지 않으며 ctime을 설치/생성 시간으로 해석하지 않는다. 새 실패 진단에는 원값·경로 없는 boolean 변화 종류가 들어간다.

**다음 행동:** [Mac 담당자 안내](MAC_ENDPOINT_HANDOFF_2026-10-29.md)의 두 도구를 함께 새로 받고 같은 DMG를 새 JSON 이름으로 재검사한다. 성공 JSON 또는 새 Diagnostic 한 줄을 받아 대조한다. PKG도 보유한 허가 파일로 별도 실행한다. 내부 코드 미지원은 실기기 성공 여부와 별개다.
