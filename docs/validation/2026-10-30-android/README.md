# Android 실제 APK·가상기기 검증 — 2026-10-30

기준 코드: 74b8b17. 실제 APK 2개는 이 PC의 기존 Android 프로젝트 빌드 산출물이다. 합성 파일로 대체하지 않았다. 원본 APK·Manifest·개인 경로·캡처·원본 결과는 Git에 포함하지 않는다. 공개 가능한 집계만 [evidence.json](evidence.json)에 기록했다. 운영 DB·사용자 계정·배포에는 변경이 없다.

## 결과와 범위

Android 16(API36) Google APIs x86_64 가상기기, Chrome 133.0.6943.137에서 실제 APK A의 **선택→읽기 동의→Worker 검사→별도 분석 동의→요약 저장→조회→JSON 다운로드→재검증**을 확인했다. PC 브라우저에서 같은 시험 계정으로 Android 결과와 비교 이력을 조회했다. 앱 설치·실행 검증이나 모든 모바일 형식의 완료를 의미하지 않는다.

| 검증 | 확인 결과 |
|---|---|
| 선택만 한 상태 | 파일 이름/크기 표시, 읽기 동의 해제·검사 비활성 |
| 읽기 동의 후 검사 | 기기 내 완료, 별도 저장 전 원본 미전송 안내 |
| 별도 분석 동의 | 동의 전 요약 저장 비활성, 동의 후 저장 성공 |
| 실제 APK A 결과 | 검토 2·참고 2·미검사 4 |
| Android JSON 다운로드 | 실제 파일 내려받기 및 PC로 복사 후 비교 성공 |
| SDK 독립 대조 | 항목 ID·상태·위험도·근거 모두 일치 |
| DB 저장값 | Android 다운로드 전체 report와 일치 |
| 동일 자산 재검증 | 자산 1개·실행 2개, 비교 변경 0·동일 4·비교 불가 4 |
| 읽기 동의 취소 | 읽기 동의 해제, 검사·저장 비활성 확인 |
| APK B에서 A로 변경 | 기존 읽기 동의가 해제되고 검사 비활성 확인 |
| PC 동일 계정 교차 조회 | 같은 자산·두 실행 및 검토 항목 조회 성공 |
| 별도 시험 계정 | 타인 자산 404, 자산 목록 비어 있음 |

진행 중 취소 버튼 클릭으로 큰 파일 Worker가 즉시 중단되는지는 이번 소형 실제 APK 흐름에서 별도로 계측하지 않았다. 파일 변경 검증은 읽기 동의 초기화 범위이며 모든 중단 경합 조건을 보증하지 않는다.

Android Studio APK Analyzer에서 APK A의 목록과 복원 Manifest를 열었다. SDK Build-Tools 30.0.3 AAPT2 출력과 사이트의 실제 범위 읽기 파서를 두 APK에 적용했다.

두 APK는 독립 SDK apksigner verify 종료 코드 0이었다. 이를 사이트의 서명 신뢰 검사 통과로 바꾸지 않는다. 서명·코드/의존성·중첩 앱·명시되지 않은 cleartext는 미검사로 유지했다. Android 브라우저는 영어 결과를 생성해 한국어 독립 보고서와 번역 문구 대신 구조화된 근거 필드를 대조했다. 저장 보고서와 Android 다운로드는 전체 report를 비교했다.

## 검증 중 이슈와 조치

1. 구형 SDK의 Java/JAXB 오류와 Emulator 가속 검사 실패: 사용자 승인·Google 약관 동의 후 공식 안정 도구로 업데이트했다. Emulator 30.6.5→37.2.13, Platform-Tools 31.0.2→37.0.1. 기존 Android 11 부팅 및 WHPX 가용을 확인했다. Chrome 83 환경을 현대 브라우저 검증으로 계산하지 않고 별도 API36 AVD를 생성했다.
2. Android 16 초기 부팅의 시스템 UI/Play 서비스 ANR: 소프트웨어 렌더링 대신 GPU auto, CPU 4개, RAM 2GB로 시험 가상기기만 재시작했다. 사용자 승인 후 시스템 UI 재시작으로 홈 화면을 복구했다. Windows 보안 기능·BIOS·Defender는 변경하지 않았다.
3. 창이 화면 밖에 표시됨: 새 시험 AVD의 창 좌표 80/80·배율 0.3을 지정해 표시를 복구했다. 기존 AVD·모니터 설정은 보존했다.
4. 데스크톱 문자 입력이 Android에 전달되지 않음: 사용자의 명시적 승인 후 ADB 터치·문자 입력으로 시험 흐름을 진행했다. Google 개인 계정은 사용하지 않았고 Chrome 약관·초기 개인정보 선택은 사용자가 직접 처리했다.
5. 시험 서버 자동 종료와 Worker 로딩 실패: 임시 서버의 40분 수명 만료를 확인했다. 기존 임시 DB를 복구해 Android 다운로드와 저장값을 대조하고 재검사를 성공시켰다. 제품 오류나 운영 장애로 확정하지 않는다. 포트 중복 시 health 응답을 잘못 인정할 수 있는 시험 헬퍼에 포트 점유 검사/자식 종료 감지를 추가했고, 점유된 포트에서는 DB 생성 전에 거절됨을 확인했다.
6. Android 화면 전환 중 접근성 빈 루트: 이전 XML을 재사용하지 않고 새 덤프 성공을 요구하도록 시험 스크립트를 보완했다. 체크 표시는 접근성 checked 값만 신뢰하지 않고 실제 스크린샷과 버튼 상태를 함께 확인했다.

## 회귀와 도구 보안

관련 회귀 테스트: 통과 26·실패 0·건너뜀 1. 링크 생성이 허용되지 않아 경계 테스트 1개가 건너뛰어졌으며 통과로 합산하지 않았다. TypeScript/production 빌드와 클라이언트 경계 검사를 통과했다. 중단 설치로 누락된 Next 16.4.2 파일은 공식 동일 버전 패키지로 복구했다. 제품 소스·lockfile 버전은 바꾸지 않았다.

Android Studio Rabbit 2 2026.2.2는 별도 폴더에 배치하고 Google LLC 서명을 확인했다. 기존 시작 메뉴·프로젝트·Gradle은 보존했다. 프로젝트 신뢰/Defender 예외 창은 사용자가 직접 닫았다. 번들 Java의 공식 인증서 완화 조치와 Stable/LTS 차이는 [도구 보안 검토](../../ANDROID_TOOLCHAIN_SECURITY_2026-10-30.md)에 기록했다. 전체 IDE/Java 무취약점 판정은 아니다.

## 남은 범위

검증 후 직접 시작한 loopback 시험 서버·임시 PostgreSQL·시험 가상기기를 종료했다. APK·원본 결과·캡처와 임시 DB 파일을 삭제하지 않았다. 가상기기는 읽기 전용 세션이었으므로 Chrome의 첫 실행 선택 등 세션 내 변경은 재실행 시 다시 필요할 수 있다. 이 문서의 성공은 운영 배포 반영이나 상시 시험 서버 제공을 의미하지 않는다.

실물 Android·실제 AAB/APKS/XAPK 파일 대조·큰 파일 실행 중 취소 계측·서명 신뢰·설치/런타임·의존성/악성코드 분석은 별도다. iOS 실기기 및 기존 R01/R02 등도 이 결과로 완료하지 않는다. **이번 실제 APK 및 Android 가상 브라우저 흐름은 확인했으며, 2단계 전체는 진행 중이다.**
