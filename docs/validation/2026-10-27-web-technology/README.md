# 웹 기술 관찰 검증

기준: e195d85 이후 로컬 수정본, web.compare 1.1.0, catalog 2026-10-27.1.

- 122개 자동 회귀 및 타입 검사 통과. PHP2Shell 네 분기의 경계·충돌·미확인 버전, Django/Spring 경계, Next.js/RSC와 서버 패키지 버전 구분, 비밀 배너 제외, 오류 응답 미검사를 확인했다.
- 모의 DNS/HTTPS에서 scanner → PC/모바일 엔진을 대조했다. PHP/8.4.26 선언에서 프로필별 PHP2Shell 경고 2개씩, 총 4개가 발생했다. 실제 공격이 아니라 통제된 헤더 fixture다.
- 분리 production 빌드 통과.
- `live-observation.json`: 로컬의 새 scanner로 정식 프로젝트 루트에 HEAD **1회** 실행, HTTP 200. React RSC 관련 응답 흔적을 관찰했지만 버전은 unknown이며 React2Shell 적용 여부도 미검사다. PHP 사용/미사용을 확정하지 않았다. 이 요청은 새 코드가 운영 배포됐음을 증명하지 않는다.
- 공개 웹에서 숨겨진 언어·실효 버전·전체 의존성을 식별하지 못한다. 공격·추가 경로 탐색·원본 코드 수집·운영 DB 변경·배포 없음. 새 UI 실제 클릭 검증은 아직 하지 않았다.

카탈로그 근거와 미지원 범위: [보안 권고 문서](../../WEB_TECHNOLOGY_ADVISORIES.md).

## 후속 검증 완료

이후 실제 로컬 브라우저에서 관리자와 일반 회원의 PC/모바일 비교 저장을 확인했다. browser-web-results.png에 RSC 흔적·버전 미확인·CVE 적용 미검사 표시를 남겼다. 앞의 UI 미실행 문구는 최초 관찰 시점의 기록이다. 최신 전체 회귀는 127/127이다. 별도 통제된 6.5초 HEAD 지연 회귀를 통과하도록 헤더 대기를 15초(전체 20초)로 조정했으며, 최초 간헐 실패의 원인을 확정한 것은 아니다. 추가 브라우저 검증도 공개 루트 HEAD만 사용했다.
