## 2단계 완료를 막는 항목

1. **R01 운영 DB 간헐 오류:** TCP 휴면 연결 방어 및 관리형 HTTPS 전환 후에도 첫 읽기 시간 초과가 관찰됐다. 준비 검사의 고정 SELECT만 일시 오류 1회 재시도한다. 최근 준비 상태 200은 확인했지만 재발하지 않는다고 확정하지 않는다. 보호를 꺼서 성공시키지 않았다.
2. **R02 관리형 DB 권한·복구:** 제공자 관리 자격의 실제 권한 분리, 키 유출 영향과 백업 복구 훈련은 미완료다. 로컬 최소 권한 PostgreSQL의 통합 성공을 운영 제공자의 독립 역할/RLS 보장으로 바꾸지 않는다.
3. **플랫폼 고유 검증:** 현재 게스트의 조건별 SSH 실효 설정, 실제 Mac의 서명/공증, Android/iOS의 플랫폼 분석 도구 대조가 남았다. 가상 파서·통신 검증은 진행했으며 그 범위만 완료로 분류한다.

준비 중 제품 기능까지 모두 구현됐다고 하거나, 지원 입력 일부의 성공으로 사이트의 모든 기능·모든 장비가 검증됐다고 표시하지 않는다. 이후 결과는 이 기록과 검토 보고서 후속 절에 갱신한다.
