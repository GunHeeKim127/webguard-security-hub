# 최종 일반 회원·가상 환경 검증 — 2026-10-28

## 결론

**1단계 완료 / 2단계 진행 중.** 지원 기능의 구현·격리 DB 검증과 실제 플랫폼 전체 검증은 구분한다. 일반 회원도 본인 자산을 검사·저장·재검증할 수 있다. 관리자 차단 관리 기능은 고객 기능으로 개방하지 않는다. Cloud·IoT·Container·예약은 준비 중이며 외부 AI는 현재 운영 설정상 비활성이다.

## 보안·검증 기준

- 전체 자동 회귀 152개, 타입 검사와 production 빌드/클라이언트 경계 검사를 확인한다. 실제 격리 DB 전체 통합은 계정 분리·9종 모듈·무결성·보관·차단 해제를 통과했다. 합성 자료는 제품의 기본 입력이나 새 운영 자산으로 넣지 않았다.
- DevTools에서 전달된 JavaScript를 완전히 숨길 수 없다. 서버 전용 DB 경계, 비공개 환경변수, 소스맵 미발행/404, API 최소 응답·no-store, 빌드의 서버 SQL/비밀 패턴 검사를 적용했다. 패턴 미검출은 모든 비밀 부재의 증명이 아니다.
- SQL 검토는 정적 단서이며 실제 쿼리를 실행하지 않는다. 문자열 조합·Unsafe API·PUBLIC 권한·definer 경로의 검토 신호와 행 번호를 표시한다. 매개변수 호출 흔적을 전체 안전으로 통과시키지 않는다.
- 앱 런타임은 고정 SQL과 값 바인딩·세션 사용자 조건을 유지한다. DDL/다중 명령/위험 함수 차단은 앱 방어이며 탈취된 관리형 DB 자격의 실제 ACL을 대체하지 않는다.
- 캡처 원본·환경 파일·복구 번들·DB 상세·실제 설정 원문은 Git에 올리지 않는다. defend-captures는 사용자 요청으로 삭제하고 제외 규칙을 추가했다.

## 2단계 완료를 막는 항목

1. **R01 운영 DB 간헐 오류:** TCP 휴면 연결 방어 및 관리형 HTTPS 전환 후에도 첫 읽기 시간 초과가 관찰됐다. 준비 검사의 고정 SELECT만 일시 오류 1회 재시도한다. 최근 준비 상태 200은 확인했지만 재발하지 않는다고 확정하지 않는다. 보호를 꺼서 성공시키지 않았다.
2. **R02 관리형 DB 권한·복구:** 제공자 관리 자격의 실제 권한 분리, 키 유출 영향과 백업 복구 훈련은 미완료다. 로컬 최소 권한 PostgreSQL의 통합 성공을 운영 제공자의 독립 역할/RLS 보장으로 바꾸지 않는다.
3. **플랫폼 고유 검증:** 현재 게스트의 조건별 SSH 실효 설정, 실제 Mac의 서명/공증, Android/iOS의 플랫폼 분석 도구 대조가 남았다. 가상 파서·통신 검증은 진행했으며 그 범위만 완료로 분류한다.

준비 중 제품 기능까지 모두 구현됐다고 하거나, 지원 입력 일부의 성공으로 사이트의 모든 기능·모든 장비가 검증됐다고 표시하지 않는다. 이후 결과는 이 기록과 검토 보고서 후속 절에 갱신한다.
