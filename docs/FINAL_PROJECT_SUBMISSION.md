# 나의 앱 프로젝트 3/3 — 최종 제출

## 이번에 만든 것

VELTHARA(WebGuard)는 웹사이트·PC·모바일 앱·가상화·네트워크의 지원 범위를 점검하고, 발견한 위험의 근거와 개선 방법을 안내하는 통합 보안 진단 플랫폼입니다. 보안 관리가 필요한 개발자가 검사 결과를 이해하고 수정 후 다시 확인할 수 있도록 만들었습니다.

1단계에서는 공개 도메인의 보안 헤더·TLS 검사와 계정·결과 저장 기반을 만들었습니다. 2단계에서는 PC·모바일 웹 응답 비교와 제공 소스의 지원 보안 단서 검토를 추가했습니다. Windows·Linux·macOS 및 모바일 파일, VM·네트워크 설정의 지원 범위를 확장하고 개선 안내·재검증·오류 처리를 보완했습니다. 3단계에서는 항목별 조치·근거 메모·변경 이력·추세·JSON/TXT/HTML 보고서를 연결하고, 접근 보호와 Linux 디코이 격리·재부팅 후 자동 시작을 검증했습니다.

화면과 API는 Next.js·React·TypeScript로 구현하고, PostgreSQL에 계정별 자산·결과·조치 이력을 저장하며 Vercel에 배포했습니다. 파일 원본을 보내지 않는 브라우저·로컬 요약과 서버가 받은 자료를 검사하는 경로를 구분합니다. 기록은 최근 30일을 표시하고 오래된 자료는 별도 비공개 보관 경로로 이관합니다.

이번 제출은 1~3단계까지의 핵심 기능 구현·검증 성과입니다. 사이트 전체의 최종 완성을 뜻하지 않으며 서비스는 계속 개발 중입니다.

## 확인하는 방법 — 3단계 이내

1. 결과물 URL에 접속해 회원가입 또는 로그인하고, 검사 선택 화면에서 모듈과 사용 안내를 확인합니다.
2. 소유하거나 점검 허가를 받은 도메인·지원 파일·설정 자료 하나로 검사하고 결과를 저장합니다. 웹은 상세 경로 없는 도메인을 사용하며, 파일은 최대 1개 선택 후 읽기 동의와 저장 동의를 순서대로 진행합니다.
3. 내 결과에서 관찰값·개선 방법·미확인 범위를 확인합니다. 같은 자산을 수정 후 재검사해 비교하고, 조치 상태·근거·변경 이력·추세·보고서 다운로드를 확인합니다. 수동 종료와 실제 후속 검사 통과는 따로 표시합니다.

## 바뀐 점과 그 이유

처음의 웹 기본 진단을 PC·모바일·가상화·네트워크까지 확장하고, 단순 결과 조회에서 조치와 재검증을 이어가는 서비스로 발전시켰습니다. 사용자가 무엇을 고치고 나중에 무엇을 다시 확인해야 하는지 추적할 수 있도록 하기 위해서입니다.

베타 피드백을 반영해 실제 관찰값·검사 기준·다음 행동을 구분하고 HTTP 상태 코드, 지원 파일, 오류 원인과 해결 방법을 보완했습니다. 파일은 한 번에 1개로 통일하고 선택·읽기·저장 동의를 구분해 사용자가 헷갈리는 부분을 줄였습니다.

일반 회원이 지원 기능을 이용하도록 하고, API의 계정별 조회·수정 조건과 SQL 매개변수 바인딩을 검증했습니다. 원본·민감 정보의 불필요한 노출을 줄이고 미확인 자료를 안전이나 취약점 확정으로 표시하지 않도록 했습니다. 간헐 503에는 지연된 DB 읽기의 실제 취소·복구·정리를 적용했습니다.

최종 회귀 219개와 실제 API·임시 PostgreSQL 통합, 타입·빌드·브라우저 코드 경계 검사를 통과했습니다. 운영 일반 회원의 결과·조치·보고서 내용도 대조했습니다. 수정 후 준비 조회 8회와 접속 보호 조회 8회는 모두 200이었으며 장기 안정성은 계속 관찰합니다.

## AI에게 맡긴 일과 내가 판단한 일

AI에게는 기존 코드·문서 분석, 화면·API·DB 기능 구현, 오류 재현과 수정, 자동 회귀와 실제 API/DB 통합 시험, 운영 화면 대조 및 문서 정리를 맡겼습니다.

저는 서비스 대상과 목표를 정하고, 일반 가입 고객도 지원 기능을 사용할 수 있어야 한다는 원칙, 계정별 데이터 분리, 최근 30일 표시와 별도 보관, 파일 1개 제한, 관리자 차단 해제, 이해하기 쉬운 사용 안내와 정직한 미확인 표시를 결정했습니다.

또한 베타 피드백을 전달하고 수정 우선순위를 요청했으며, VM 환경을 준비해 Linux 검증 명령을 직접 실행했습니다. Mac 담당자의 실사용 결과와 모바일 확인을 전달했습니다. 실제 환경 확인·사용자 전달 결과·격리 시험의 근거를 구분하고, 미검증 범위를 남기는 제출 방향을 선택했습니다.

## 다음에 할 일

사이트는 아직 전체 완성 상태가 아닙니다. 현재 준비 중인 Cloud·Container·IoT 모듈을 사용 가능한 환경과 우선순위에 맞춰 순차 개발하고, 기존 모듈의 지원 파일·OS·장비 범위를 확장하겠습니다. 외부 AI 분석도 설정과 검증 조건을 갖춰 보조 기능으로 고도화하겠습니다.

베타 피드백을 계속 반영하며 장기·휴면 후 로그인·검사·저장·조회 흐름을 확인하겠습니다. 제공자 백업 복구, 운영 접속키 관리와 DB 권한 분리/RLS 구조, 디코이의 외부 운영 트래픽 연동, 추가 실기기 검증을 후속 과제로 진행하겠습니다.

운영 고객 트래픽의 자동 허니팟 격리, 모든 공격·DDoS 방어, 실효 DB RLS, 전체 플랫폼·제공자 복구 검증은 완료 범위에 포함하지 않습니다.
