# 진단 작전실

참조 UI: https://auth-security-lab-game.vercel.app/

주소 입력이 먼저 있고 실행 후 그 아래에 작전실이 나타납니다. 서버가 실제 수행하는 대상 승인 → 공개 DNS/TLS → 응답 헤더 → DB 저장 이벤트를 NDJSON으로 전달합니다. 진행 단계는 점멸하고 동작 줄이기 설정에서는 점멸하지 않습니다. 빠르게 끝나는 단계는 완료 상태로 보일 수 있습니다. 가짜 진행률은 만들지 않습니다.

주소 변경은 현재 요청을 취소하고 화면 로그·결과·개선안을 비웁니다. 같은 주소를 다시 실행해도 새 로그로 시작합니다. 이미 저장된 DB 기록과 감사 이벤트는 보존됩니다. 저장 직전에 취소한 요청의 결과는 DB에 남을 수 있습니다. 실패한 실행에 이전 성공 결과를 섞어 보여주지 않습니다.

현재 실행의 주소·시간·단계·오류 코드·최종 결과는 JSON으로 다운로드합니다. 상세 로그는 브라우저 메모리에만 있으므로 새로고침 전에 필요한 기록을 저장하세요. 과거 DB 기록을 선택하면 최종 결과만 볼 수 있고 당시 상세 진행 로그는 복원하지 않습니다. 같은 도메인의 DB 결과는 최신 성공 결과 하나로 갱신됩니다.

진단 기록 아래에서 API 미사용 기본 안내를 열거나 AI 개선안을 요청할 수 있습니다. AI는 Groq → Gemini 순서로 전환하고 모두 실패하면 기본 안내를 표시합니다. 저장된 AI 답변은 재호출 없이 재사용하고 실제 제공자·모델을 표시합니다.

허브 최근 24시간 이벤트와 현재 실행 로그는 서로 다릅니다. 외부 웹사이트의 전체 트래픽을 감시하지 않습니다. 헤더 4종의 존재 여부만 확인하며 취약점 공격 검증이나 안전성 보장은 하지 않습니다.
