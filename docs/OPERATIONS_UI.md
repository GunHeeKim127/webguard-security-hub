# 진단 작전실

참조 UI: https://auth-security-lab-game.vercel.app/

주소 입력이 먼저 있고 실행 후 그 아래에 작전실이 나타납니다. 기본 공개 모드는 주소·권한 선언 확인 → 공개 DNS/TLS → 응답 헤더 → DB 저장 이벤트를 NDJSON으로 전달합니다. 별도 사전 등록 없이 공개 도메인과 권한 체크로 요청하며 주소 변경 시 체크도 초기화합니다. 진행 단계는 점멸하고 동작 줄이기 설정에서는 점멸하지 않습니다. 빠르게 끝나는 단계는 완료 상태로 보일 수 있습니다. 가짜 진행률은 만들지 않습니다.

주소 변경은 현재 요청을 취소하고 화면 로그·결과·개선안을 비웁니다. 같은 주소를 다시 실행해도 새 로그로 시작합니다. 이미 저장된 DB 기록과 감사 이벤트는 보존됩니다. 저장 직전에 취소한 요청의 결과는 DB에 남을 수 있습니다. 실패한 실행에 이전 성공 결과를 섞어 보여주지 않습니다.

현재 실행의 주소·시간·단계·오류 코드·최종 결과는 JSON으로 다운로드합니다. 상세 로그는 브라우저 메모리에만 있으므로 새로고침 전에 필요한 기록을 저장하세요. 과거 DB 기록을 선택하면 최종 결과만 볼 수 있고 당시 상세 진행 로그는 복원하지 않습니다. 같은 계정·도메인의 DB 결과는 최신 성공 결과 하나로 갱신됩니다. 다른 계정의 결과는 조회하거나 덮어쓰지 않습니다.

진단 기록 아래에서 API 미사용 기본 안내를 열거나 AI 개선안을 요청할 수 있습니다. AI는 Groq → Gemini 순서로 전환하고 모두 실패하면 기본 안내를 표시합니다. 저장된 AI 답변은 재호출 없이 재사용하고 실제 제공자·모델을 표시합니다.

내 계정의 최근 24시간 이벤트와 현재 실행 로그는 서로 다릅니다. 외부 웹사이트의 전체 트래픽을 감시하지 않습니다. 공개 루트의 HEAD 응답과 TLS 연결에 대해 헤더 정책값·인증서·쿠키 속성·CORS·서버 식별 헤더를 기본 검사합니다. 취약점 공격 검증이나 안전성 보장은 하지 않습니다.

상세 결과는 기본 검사 통과·검토 필요·참고·확인 불가로 구분하고, 심각도와 값이 제거된 관찰 근거를 보여줍니다. 각 카드의 개선·확인 방법은 처음에는 접혀 있으며 제목을 누르거나 키보드 Enter로 펼칠 수 있습니다. 기본·AI 개선안의 펼치기/접기 버튼은 이미 받은 내용을 표시하므로 API를 호출하지 않습니다. 이전 결과에 상세 검사가 없다면 재진단 안내를 표시합니다.

관리자에게는 위험 접근 탐지·IP 차단 현황을 보여줍니다. DB 최신 기록은 대시보드 갱신 때 반영합니다. 실시간 push 알림은 없습니다. 보호 서버에서 차단된 사용자에게는 5분 차단 또는 블랙리스트 경고가 언어별로 표시됩니다. 복구 방법과 탐지 범위는 [ACCESS_DEFENSE.md](ACCESS_DEFENSE.md)를 참고하세요.
