# 일반 고객 진단 권한 — 2026-10-22

## 요구와 기존 문제

이 서비스는 가입 고객이 자신의 허가된 자산을 직접 진단하는 서비스다. 기존 구현은 회원가입으로 생성한 viewer를 조회 전용으로 취급하고 admin/analyst만 진단을 허용했다. 따라서 일반 회원의 파일 선택 버튼뿐 아니라 진단 API도 막혔다. 관리자 세션의 정상 동작만으로 고객 동작을 검증할 수 없었다.

## 변경

- 기존 DB의 viewer를 UI에서 **일반 회원**으로 표시하고 본인 진단·저장·재검증을 허용한다. 신규 가입과 이미 가입한 계정 모두 적용되며 계정 역할·비밀번호·이력은 변경하지 않는다.
- Endpoint/Mobile/모듈 진단뿐 아니라 기존 웹 진단과 활성화된 경우의 본인 결과 AI 요청에도 같은 고객 권한을 적용한다. 외부 AI 활성화 여부와 사용량 제한은 유지한다.
- 본인 웹 자산의 집계 수집 키 발급·교체는 허용한다. 소유자가 다른 자산은 404다.
- 역할은 가입 요청에서 지정할 수 없고 DB 가입 함수가 계속 viewer를 강제한다. 관리자 IP 목록은 admin 전용이다. 고객에게 SQL 관리 권한을 부여하지 않는다.
- 파일 선택과 파일 읽기는 구분한다. 파일은 명시적 읽기 동의 후에만 검사하고, 원본을 전송하지 않는다. 별도 동의와 자산 이름·유효 요약이 있어야 저장한다.
- 6개 언어의 일반 회원 표시와 가입 안내를 수정한다. 기존 테마와 화면 구조를 유지한다.

## 검증

- 일반 회원 역할의 실제 로컬 브라우저에서 Endpoint 파일 선택 → 읽기 동의 → Worker 검사 → 별도 동의 → 요약 저장 완료. ASLR/NX/W+X 경고 3개·미검사 1개를 확인했다. 테스트 파일과 결과는 운영 DB가 아닌 분리된 loopback 앱·임시 PostgreSQL에만 있다.
- 100개 단위/회귀 검사 및 production 빌드 통과. HTTP/DB 통합은 실제 가입 계정의 진단·재검증 이력, 타 계정(관리자 포함)의 결과 접근 404, 관리자 IP 비노출, SSRF 거절, 필수 동의·비로그인 거절을 포함한다.
- 운영 테스트 파일·계정을 추가하거나 기존 고객의 역할을 승격하지 않는다. Git 배포 완료와 운영 후속 검증은 별도로 확인한다.

이전 기록의 viewer 거절은 과거 정책 검증 결과다. 현재 권한 기준은 이 문서와 SECURITY_POLICY.md의 고객 서비스 정책을 따른다. 별도의 간헐적 보호 DB 조회 시간 초과 문제와 이번 회원 권한 수정은 구분한다.
