## 다음 수행 순서와 완료 기준

1. **운영 안정성:** 관찰 기간·지연 목표를 정하고 휴면 후 로그인·검사·저장·조회까지 기록합니다. 보호 오류·저장 누락·중복·계정 혼합과 장애 복구 결과를 확인합니다. 상태 API만으로 완료하지 않습니다.
2. **백업 복구:** 실제 백업·보존 범위를 확인하고 승인된 별도 환경에서 데이터 복원·무결성·권한·두 계정 격리를 대조합니다. 운영 DB를 덮어쓰지 않으며 복구 소요 시간과 허용 손실을 확인합니다.
3. **플랫폼 후속 확인:** Android 실물, iPhone 수정 후 저장과 지원 OS 보안 값의 독립 대조를 진행합니다. Mac PKG 실환경 동작은 담당자 확인으로 완료했습니다. OS/도구 버전과 기대 결과를 구분하며 개인 경로·원본·비밀은 공개하지 않습니다.
4. **확장 범위 확인:** 실제 추가 가상화 자료와 운영 방화벽을 대조합니다. 설정 선언을 장비 실효 상태나 모든 공격 방어의 증명으로 해석하지 않습니다.
