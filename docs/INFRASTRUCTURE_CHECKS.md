# VM·네트워크 설정 점검 — 2026-10-23

공개 문서는 사용법·지원 범위·검증 상태만 제공합니다. 내부 운영 절차와 상세 구현·환경 식별 정보는 공개하지 않습니다.

## 지원 형식

| 영역 | 선택할 자료 | 검사 범위 |
| --- | --- | --- |
| VMware | `.vmx` 또는 동일 설정 텍스트 | 명시된 공유·콘솔·NIC 설정 |
| OVF | `.ovf` XML 설명 파일 | 가상 시스템 설명 구조. 실제 공유·격리는 미확인 |
| libvirt | `domain` 형식의 `.xml` | 지원되는 파일 시스템 공유·NIC·그래픽 콘솔 선언 |
| VirtualBox | 지원 구조의 `.vbox` | 명시된 클립보드·드래그앤드롭·공유 폴더·원격 디스플레이 선언 |
| GNS3 | GNS3 2.x `.gns3`·동일 JSON | 노드·연결 및 지원 구성 선언 |
| DNS | BIND 9 `.conf` 또는 설정 텍스트 | 지원되는 재귀·영역 전송·검증 설정 선언 |
| 라우터 | Cisco IOS 계열 `.cfg`, `.conf`, `.txt`, 확장자 없는 설정 | RIP·EIGRP·IS-IS의 지원 선언·보완 안내 |

확장자가 같아도 실제 구조가 다르면 확인 불가로 처리합니다. XML의 모든 벤더 확장·버전과 라우터의 모든 문법을 지원하지는 않습니다. 값이 없으면 실제 비활성·안전으로 추정하지 않습니다.

## 현재 직접 검사하지 않는 형식

`.ova`와 `.gns3project`는 묶음, `.vmdk/.vdi/.vhd/.vhdx/.qcow2` 등은 디스크, `.pcap/.pcapng`는 패킷 캡처, `.pkt/.pka`는 별도 프로젝트 형식입니다. 선택 창에 보이는 것과 검사 지원은 다릅니다. 원래 도구에서 위 표의 설정/설명 파일을 내보내세요. 파일 이름만 바꾸지 마세요.

## 사용 순서

1. Network는 자료 종류를 먼저 선택합니다. Virtualization은 지원 구조를 자동으로 구분합니다.
2. 허가된 설정 파일 하나를 선택하고 읽기를 허용한 뒤 읽기 버튼을 누릅니다. 직접 입력도 가능합니다. 키·암호 값은 제거하고 필요한 명령 구조는 유지하세요.
3. 검사 권한을 확인하고 진단합니다. 제공되는 관찰·보완 방법·미확인 항목을 함께 읽으세요.
4. 실제 적용은 해당 하이퍼바이저·장비에서 따로 대조합니다. 파일 경로가 다르다는 이유로 취약하다고 판정하지 않습니다.

파일은 전송 형식을 포함해 최대 64 KiB입니다. UTF-8과 BOM이 있는 UTF-16 텍스트를 지원합니다. 원문을 현재 검사 요청에서 분석하며 VM·디스크·참조 URL을 실행하거나 열지 않습니다. GNS3 프로젝트만으로 장비의 실제 라우팅·DNS 설정을 확정하지 않습니다.
