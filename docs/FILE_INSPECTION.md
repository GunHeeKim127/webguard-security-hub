# 실행 파일·모바일 패키지 점검

공개 문서는 사용법·지원 범위·검증 상태만 제공합니다. 내부 운영 절차와 상세 구현·환경 식별 정보는 공개하지 않습니다. 이전 세부 검토 자료는 별도 비공개 보관본으로 관리합니다.
