정식 UI·다운로드 JSON·독립 DB/API·규칙 테스트를 대조했습니다. 입력 동의/경합·필수 파일·경고 요약·오류 안내·제한된 보호 오류 재시도를 수정했고, 98개 테스트·최종 빌드·타입·보안/언어 smoke·전체 DB 통합을 통과했습니다. 파일 미선택·빈/손상 파일·미동의 거절과 PE/IPA 경고는 실제 로컬 브라우저에서도 확인했습니다. 테스트 파일은 배포 제외이며, 운영 DB의 일시 실패 근본 원인은 별도 확인 대상입니다. [세부 기록](PRODUCTION_REVIEW_2026-10-22.md).

## 2026-10-22 · 현재 PC에서 재검증

94개 테스트·별도 production 빌드·타입·보안/6개 언어 HTTP smoke를 다시 통과했다. Linux 합성 대조와 실제 Windows PE 요약 처리를 확인했다. Kali VM은 실행 중이지만 SSH/root 키 인증은 거절돼 실제 설정 검증은 미완료다. 로컬 SQL·실제 환경 파일이 없어 DB 통합과 운영 로그인/저장 흐름을 재실행하지 않았다. Windows 서명 unknown, 운영 readiness의 일시 오류 후 회복을 포함한 정확한 범위는 [현재 환경 검증 기록](LOCAL_ENVIRONMENT_VALIDATION.md)에 있다. 아래는 이전 환경에서 수행한 이력으로 보존한다.

## 후속 수정: 버튼 → 전용 작전실 이동

사용자 요청에 따라 홈 내부 폼 펼침과 밝은 테마를 취소했습니다. Web 버튼은 기존 `/?view=web`, Mobile은 `/workbench/mobile`, Endpoint는 `/workbench/endpoint`로 이동합니다. 별도 `/workbench/results`에서 전체 기록을 확인하며 각 작전실은 해당 종류의 기록만 표시합니다. 기존 로그인 화면의 시각 구성은 `86557eb` 기준으로 복원했습니다. 아래는 이전 배포의 검증 이력이며 이번 변경의 검증 결과는 후속 기록에 명시합니다.

- 최종 빌드·TypeScript 통과. 전체 독립 DB 통합 검증을 다시 통과했으며 새 페이지의 링크·검사 종류·로그인 요구·결과 전용 화면·404를 추가 검증했습니다.
- 보안 HTTP smoke와 6개 언어 smoke 통과. 검사 엔진·파일 파서·인증/API의 동작은 변경하지 않았습니다.
- 이전 로그인 패널의 소스·문구·이미지·크기와 현재 패널을 비교해 일치했습니다. 로그인 성공 후 목적지만 검사 선택 홈으로 유지했습니다.

- 공식 주소의 실제 브라우저에서 밝은 로그인 화면, 임시 계정 로그인 후 `/workbench`, 8개 카드, Endpoint 관련 폼, 파일 읽기 동의 전 비활성 상태를 확인했습니다.
- 실제 UI에서 Linux 검토 필요 샘플을 저장한 뒤 개선 샘플로 재검증해 개선 관찰 5개·악화 0개, 접이식 개선 안내와 로그아웃을 확인했습니다.
- 운영 HTTP/API의 별도 교차 검사: admin/viewer 새 홈, 기존 웹 화면 유지, 회원가입·중복 해시 보존·viewer 강제·다중 세션, 소유 예제 사이트의 실제 HEAD/TLS 및 단계 스트림·동일 결과 ID 갱신, 모듈 재검증 2개 이력, PC/모바일 응답 비교, 집계 키 해시·수신·신호, 잘못된 키/원본 IP 거절, Windows/macOS/IPA 요약 및 원문 경로 거절을 통과했습니다.
- 별도 두 계정의 같은 호스트 기록과 이벤트 분리, 관리자 포함 타 계정 AI ID 거절, AI 운영 비활성, 로그아웃 후 401을 확인했습니다.
- 테스트용 계정·세션·결과·자산·집계만 정리했습니다. 기존 사용자·비밀번호 해시·역할·결과의 동일성을 비교했습니다. 보호 기능·AI 비활성 설정을 우회하지 않았습니다.

1. 실제 사이트가 예전 웹 중심 화면으로 열림: 인증된 루트와 로그인 성공 동선을 플랫폼으로 통일하고 기존 작전실은 명시적인 링크로 보존.
2. 밝은 테마 안의 옛 어두운 작전실 배경: 테마와 일치하도록 대비 수정.
3. 카드 모서리 과도한 둥글기: MUI 배수 값 대신 명시적인 16px 사용.
4. 언어 전환 뒤 문서 언어가 오래된 값 유지: 문서 lang·제목 동기화 후 재검증.
5. 성공 후 오래된 오류·빠른 선택 시 조회 경합: 성공 시 오류 초기화와 현재 요청 세대에 맞춘 재조회.

## 한계

클라우드·가상화·네트워크·IoT·컨테이너, 작업 예약, 정식 보고서, 새 모듈 AI는 준비 중입니다. 카드가 있다는 사실이 검사 지원을 뜻하지 않습니다. PWA·전체 인증 흐름·악성코드·모든 CVE·실물 OS의 유효 정책·앱 서명 신뢰 전체를 검사하지 않습니다. 실제 Mac의 codesign/spctl과 실물 iOS/Android의 종단 동작은 미검증입니다. 파일 결과는 제한된 정적 관찰이며 브라우저 요약은 자기 보고입니다.

운영 Prisma 자격 증명의 광범위한 DB 권한은 앱 계층 SQL 검사로 완전한 DB ACL 격리가 되지 않습니다. MFA·메일 인증·비밀번호 복구·독립 보안 심사는 별도 과제입니다. 모든 파일·장치·미래 취약점에 대한 완벽한 안전을 보장하는 검증은 아닙니다.
