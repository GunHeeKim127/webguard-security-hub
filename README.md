## 화면 이동 정리 · 2026-11-19

웹 진단·검사 선택·모듈별 작전실·Java/JVM·GitHub·사용 가이드의 상단 메뉴를 공통 구성으로 정리했습니다. 화면마다 브랜드와 메뉴 순서가 달랐고, 전체 서비스 이동과 특정 검사의 이동이 한 줄에 섞여 있던 문제를 해결했습니다.

- 상단 브랜드는 VELTHARA, 주 메뉴는 검사 선택 → 내 결과 → 사용 가이드 순서입니다. 현재 메뉴는 강조하고 보조 기술에도 현재 위치를 전달합니다.
- 웹 진단 안에서는 기본 헤더·TLS와 PC·모바일 응답 비교, Endpoint 안에서는 실행 파일·시스템과 Java/JVM을 관련 검사로 묶습니다.
- 내 결과에는 모듈 진단 기록과 웹 진단 기록의 이동 경로를 구분합니다. 두 기록의 저장 방식은 기존대로 유지합니다.
- 언어와 계정 동작은 상단 오른쪽에 배치합니다. 모바일에서는 줄바꿈하며 표시합니다. 로그인·회원가입 화면의 디자인과 인증·검사·계정별 조회 로직은 변경하지 않습니다.

검증: 배포 빌드·형식 검사·Java 관련 회귀 테스트 6개 통과. 임시 계정의 브라우저 흐름으로 검사 선택 → 웹 진단 → 응답 비교 → Endpoint → Java/JVM → 결과 → 웹 기록 → GitHub → 가이드 이동, 언어 변경·유지, 로그아웃을 확인했습니다. 390px 화면에서도 계정·언어·메뉴가 잘리지 않는 것을 확인했습니다. 기록 앵커의 비동기 로딩과 기존 메뉴명을 가리키던 문구를 함께 보완했습니다.

상단의 별도 웹 진단 버튼은 제거했습니다. 웹 진단도 검사 선택의 Web 버튼으로 들어가며, 웹 화면에서는 검사 선택 메뉴를 상위 위치로 강조합니다. 웹 내부의 기본 헤더·TLS/PC·모바일 비교 메뉴와 내 결과의 웹 기록 연결은 유지합니다.
