## 화면 이동 정리 · 2026-11-19

공통 헤더에는 브랜드·계정·언어와 **검사 선택 · 내 결과 · 사용 가이드**만 표시합니다. 모든 모듈을 반복 나열하던 서브헤더와 큰 관련 검사 탭은 제거했습니다. 모듈 이동은 검사 선택 화면의 기존 카드에서 합니다.

- 웹사이트 기본 보안 점검과 PC·모바일 접속 환경 비교는 각 페이지의 설명 아래에서 서로 연결합니다.
- Endpoint의 Java 점검은 기존 소개 카드에서 열고, Java 점검 페이지에서는 프로그램·컴퓨터 보안 점검으로 돌아갈 수 있습니다.
- 내 결과에는 **모듈 진단 기록** 이름을 유지하고 웹사이트 점검 기록으로 이동하는 링크를 둡니다. 두 기록의 저장 방식은 기존대로 유지합니다.
- 다른 검사 화면에는 추가 이동 메뉴를 표시하지 않습니다. 로그인·회원가입 화면과 검사·인증·계정별 데이터 조회 로직은 유지합니다.

카드의 공통 모듈 목록은 유지하며 Cloud·IoT·Container는 준비 중입니다. 검사 범위가 확장된 것은 아닙니다.
